About Athios

AI that understands you. Athios is a chat assistant with a memory that lasts, built so you can see how it fits together.

A chat assistant that remembers

Athios is built around a language model that writes one word at a time, the same idea behind today's popular AI assistants. What sets it apart is memory: your conversations are saved to your account, so Athios can recall earlier messages and carry on across sessions.

It is designed to be understandable from start to finish, from the text it learns from to the website you are using now.

  • Text conversations: questions, drafts, summaries and study help
  • Your chats stay yours: only you can open them
  • Delete a chat and its memory goes with it

Good to know

Does Athios remember my conversations?

Yes. Each chat is saved to your account. When you return, reopen it and Athios continues with the earlier messages in view.

Can I delete my chats?

Yes. Delete any chat from the sidebar and its messages and memory are removed.

Who can see my chats?

Only the account that created them. Passwords are stored as salted hashes, never as plain text.

What can I use Athios for?

Questions, explanations, drafts, summaries, study notes and brainstorming. For now it works with text only.

How capable is Athios?

Athios uses a compact language model, so its answers can be simpler than those of very large assistants. Its memory helps it stay consistent across a conversation.
